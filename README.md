# 格式塔涌现 · Gestalt Emergence

> 一项关于**多模型分层协作系统中集体涌现**的可计算形式化研究。
> 核心交付：**GLA**（Gestalt Layered Architecture，格式塔分层架构）+ **GE**（Gestalt Equation，格式塔方程）。

---

## 这是什么

本项目用一套**有向、不对称、分层**的多模型协作装置（GLA），把多个小模型（1.5B / 3B）
经副导层聚合、主脑层终判，验证「集体性能可**超过其最强单一模型**」的涌现现象，
并给出涌现的可计算度量 GE。

- **GLA（架构）**：L1 主脑 → L2 副导 → L3 专家集群（1.5B × N）。
  双通道聚合（聚合简报 + 未聚合残留），跨层条件熵乘法作为结构性涌现补充机制。
  **它不是 classic multi-agent / 对等投票系统**——它是带合成聚合器的不对称分层 *synthesis*。
- **GE（方程）**：涌现度量 `M(W) = b + γ·(W/Wc)·e^{1−W/Wc}`，
  其中 `b = 0.50, γ = 0.25`，`Wc` 为峰值位置（友人数学国面定位 ≈ 0.45–0.62，待真机 W 轴扫描钉死），`M ∈ [0.50, 0.75]`。

---

## 已验证的关键事实（诚实披露）

- **密度扫描（k 轴，固定 Ẇ = 1.0）**：k8 / k10 / k12 / k15 集体准确率稳定贴 **0.93–0.95** 平台，
  均显著超过最强单体 7B（0.834），`G_anchor = 集体 − 最强单体` 恒正 +0.10 ~ +0.12。
- **护城河（非投票）**：纯投票基线 `committee0` 仅 0.59–0.61，远低于集体且被最强单体封顶
  → 增益来自**合成机制**，而非多数投票（这也是与 multi-agent 系统的根本边界）。
- **k20 进行中**：截至 2026-08-15，k20（n = 500）仍在跑，集体暂值 ≈ 0.95，护城河成立；done 后将补入 `results/density/`。
- **外部反例（必须正面解释）**：在 **C-Eval** 中文硬知识题上，集体（0.66）**未超过**最强单体（0.785）
  ——因下层小模型在该任务语言/容量上不互补、只灌噪声，聚合回归弱层均值。
  这不构成否定，而是界定了涌现的适用边界：**涌现 = 架构 × 下层相对顶层的互补信号盈余**。

## 如何复现

1. **依赖**：Python 3.13、Ollama、Qwen2.5 系列模型（1.5B / 3B / 7B）。
2. **模型权重不入库**（见 `.gitignore`，约 15 GB）：请从 Ollama 拉取 Qwen2.5 并遵守其许可。
3. **运行**：
   - 密度扫描：`src/run_density_scan.py`
   - 单点验证：`src/verify_stage2.py`
   - W 轴补扫（钉 Wc）：`src/run_wc_scan.py`
4. 结果 JSON 在 `results/`，可视化在 `reports/`、`visualizations/`。
