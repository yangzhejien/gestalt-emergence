# 格式塔方程：完整推导手册（v1.4.0）

> 本文目标：从第一性原理严格推导
> $$M = \sum_{i=1}^{k} s_i + \sum_{m\ge 1} \alpha_m \hat{W}^{2m}$$
> 其中 $s_i$ 为节点 $i$ 的无量纲基础能力，$\hat{W} = W / W_{\max}(k)$ 为归一化总连接强度，$W = \sum_{i<j} w_{ij}$，$w_{ij}\in[0,1]$。
>
> 本文基于 v1.3.0（已完成量纲收紧）与实验方案 v1，补完**两条独立推导路径**，并修复原 v1.2.0 中"六体交互记号不一致"的缺口。
>
> **结论先行**：方程在数学上由两个独立且相互印证的物理框架推出（信息论 + 统计物理），形式是 **well-defined 的偶次幂级数**；但推导依赖 3 条明确标注的"可检验假设"（A1–A3），目前是"有严格框架支撑的数学猜想"，尚非"已实验证伪/证实的定理"。

## 0. 约定与量纲基础（来自 v1.3.0）

| 符号 | 含义 | 量纲 |
|------|------|------|
| $s_i$ | 节点 $i$ 在固定基准套件（如 MMLU-200/GSM8K-100/HumanEval-50）上的得分，归一到 $[0,1]$ | 无量纲 |
| $w_{ij}$ | 节点 $i,j$ 间的连接权重，$\in[0,1]$，已归一化 | 无量纲 |
| $W$ | 总连接强度，$W=\sum_{i<j}w_{ij}$ | 无量纲（广延量，随 $k$ 增长） |
| $W_{\max}(k)$ | $k$ 节点全连接上限，$=k(k-1)/2$ | 无量纲 |
| $\hat{W}$ | 归一化连接强度，$=W/W_{\max}(k)\in[0,1]$ | 无量纲（强度量，与 $k$ 无关） |
| $M$ | 网络整体涌现能力（同量纲的基准得分） | 无量纲 |
| $\alpha_m$ | 第 $2m$ 阶涌现系数（含组合/拓扑/节点耦合因子） | 无量纲 |

**量纲自洽性**：全式无量纲。$s_i$ 与 $M$ 同是基准得分；$\hat{W}^{2m}$ 无量纲；$\alpha_m$ 无量纲。v1.2.0 中"$N_i$ 混用参数/维度/FLOPs"的问题已根除。

## 1. 信息论路径（微观机制推导）

### 1.1 单节点：能力即信息提取率

节点 $i$ 把输入分布 $X$ 映射为输出 $Y_i$。其"有效信息"定义为
$$I_{\text{eff}}(i) = I(X; Y_i)$$
在固定基准套件上，$I_{\text{eff}}(i)$ 与得分 $s_i$ 单调相关，故直接取 $s_i \triangleq I_{\text{eff}}(i)$（归一化到 $[0,1]$）。
独立工作的 $k$ 节点总信息（基线）：
$$I_{\text{indep}} = \sum_{i=1}^k s_i$$

### 1.2 两节点协同：互信息为何是二次、且偶

将节点 $i,j$ 用权重 $w$ 连成协同子网络 $N_{ij}$，处理联合输入 $X$。协同输出记为 $Y_{ij}^{\text{net}}$。

协同增益定义为协同网络相对独立基线的额外互信息：
$$\Delta_{ij} = I(X; Y_{ij}^{\text{net}}) - \big[I(X;Y_i) + I(X;Y_j)\big]$$

把连接视为在 $i,j$ 输出间建立"相关信道"，相关强度 $\rho = f(w)\approx w$（小 $w$ 线性）。将 $\Delta$ 视为 $\rho$ 的函数，在 $\rho=0$（无连接）处泰勒展开：
$$\Delta(\rho) = \Delta(0) + \Delta'(0)\rho + \tfrac{1}{2}\Delta''(0)\rho^2 + O(\rho^3)$$

- $\Delta(0)=0$：无连接则无协同。
- **偶函数性**：互信息 $I(X;Y)$ 只取决于相关性的**大小**，不取决于符号——连接是"增强"($+w$)还是"抑制"($-w$)，两者共享的信息量相同，故 $\Delta(-\rho)=\Delta(\rho)$，推出 $\Delta'(0)=0$。
- 首项：$\Delta(\rho) \approx \tfrac{1}{2}\Delta''(0)\rho^2 \propto w^2$。

**结论（引理 L1）**：两节点协同增益 $\Delta_{ij} \propto w_{ij}^2$，即**二次、且偶**。这是整个方程"偶次幂"的微观来源。

### 1.3 m-阶协同：修复"六体记号"缺口

原 v1.2.0 写"四体交互对应 $W^4$、六体交互对应 $W^6$"时，记号把"节点数"与"幂次"混为一谈，导致内部不一致。**此处重新严格定义：**

> **定义**：方程中的阶数 $m$ 指"协同所涉及的**边数**（连接数）"，不是节点数。$m$ 条边协同对应幂次 $2m$。

**物理机制（基于部分信息分解 PID / 集成信息论 IIT）**：
当 $m$ 条边构成协同结构，多体协同信息对每条边的耦合是**乘性**的——任一连接断开，协同降一阶（冗余-协同差的可加性）。即 $m$ 条边的联合协同：
$$\text{Syn}_m \propto \prod_{e=1}^{m} w_e^{\,2}$$
（每条边贡献 $w^2$，来源于 L1；连乘来源于协同的乘性增强。）

对**所有 $m$-边组合**求和。在"边近似独立"的平均场近似下（稠密网络成立）：
$$\sum_{\text{comb of }m\text{ edges}} \prod_{e} w_e^{\,2} \;\approx\; \frac{1}{m!}\Big(\sum_e w_e^{\,2}\Big)^m$$

由柯西-施瓦茨不等式 $\sum_e w_e^2 \le (\sum_e w_e)^2 = W^2$（等号当所有 $w$ 相等），均匀网络有 $\sum_e w_e^2 \approx c\cdot W^2$（$c$ 为常数），故：
$$\text{Syn}_m \propto W^{2m}$$
吸收常数入 $\alpha_m$，得第 $m$ 阶协同增益项：
$$G_m = \alpha_m \hat{W}^{2m}$$
（用 $\hat{W}$ 取代 $W$ 以达成规模无关，见 §4。）

**核对幂次**：
- $m=1$（一条边 / 两节点）：$\hat{W}^2$ ✓
- $m=2$（两条边 / 三节点路径）：$\hat{W}^4$ ✓
- $m=3$（三条边）：$\hat{W}^6$ ✓

幂次 $2m$ 严格等于"边数 $m$ × 每边 $w^2$"，**不再出现 v1.2.0 的六体记号矛盾**。

### 1.4 信息论路径总式

总协同增益为各级协同之和：
$$G_{\text{info}} = \sum_{m\ge 1} \alpha_m \hat{W}^{2m}$$
整体能力：
$$M = \underbrace{\sum_i s_i}_{\text{独立基线}} + \underbrace{\sum_{m\ge 1}\alpha_m \hat{W}^{2m}}_{\text{协同涌现}}$$

## 2. 统计物理路径（宏观相变推导）

### 2.1 节点→自旋，连接→耦合

将节点 $i$ 映射为伊辛自旋 $\sigma_i\in\{-1,+1\}$（$\sigma_i$ 表示"输出朝向"或"激活态"）。
连接权重映射为耦合常数：
$$J_{ij} = g\cdot w_{ij}$$
其中 $g>0$ 为耦合强度标度。

### 2.2 协同网络哈密顿量

$$H = -\sum_{i<j} J_{ij}\,\sigma_i\sigma_j - B\sum_i \sigma_i$$
$-J_{ij}\sigma_i\sigma_j$ 项：正 $w$ 让相邻自旋**对齐**（铁磁耦合），即"连接促协同"。

### 2.3 Landau 平均场：序参量与自由能

定义协同序参量 $\phi = \langle\sigma\rangle$（网络平均对齐度，衡量"集体是否形成一致认知"）。

平均场近似：每个自旋感受有效场
$$h_i^{\text{eff}} = \sum_j J_{ij}\langle\sigma_j\rangle + B \approx g\,\hat{W}\,\phi + B$$
（因 $\sum_j w_{ij}$ 在均匀网络 $\approx \hat{W}\cdot k$，再除以 $k$ 得 $\hat{W}$。）

自由能密度按对称性展开。因系统对 $\phi\to -\phi$ 对称（网络无偏好方向），自由能只含偶次幂：
$$f(\phi) = a\,\phi^2 + b\,\phi^4 + c\,\phi^6 + \cdots$$
其中
- $a = a_0(T - T_c)$，$T_c \propto g\,\hat{W}$（连接越强，越易对齐，临界温度越高）；
- $b,c>0$ 保证 $\phi$ 大时自由能回升、系统稳定。

### 2.4 涌现 = 序参量相变（临界点）

- 当 $\hat{W} < \hat{W}_c$（$a>0$）：极小在 $\phi=0$，网络无序，**无涌现**；
- 当 $\hat{W} > \hat{W}_c$（$a<0$）：极小移到 $\phi\neq 0$，网络自发对齐，**涌现发生**。

涌现增益取自由能下降量：
$$G_{\text{phys}} = -\Delta f = f(0) - f(\phi_{\min}) \propto \phi^2$$
平均场下 $\phi^2 = -a/(2b) \propto (\hat{W} - \hat{W}_c)$ 在临界点附近。把 $G_{\text{phys}}$ 直接展开为 $\hat{W}$ 的 Landau 级数：
$$G_{\text{phys}} = \alpha_1\hat{W}^2 + \alpha_2\hat{W}^4 + \alpha_3\hat{W}^6 + \cdots$$
系数 $\alpha_m$ 由 $a_0,b,c,T_c,g$ 决定。

**临界点预言（可检验）**：扫描 $w$，能力在 $\hat{W}_c$ 处发生跳变（二级相变），$\hat{W}_c = \sqrt{\alpha_1/\alpha_2}$（由拟合 $\alpha_1,\alpha_2$ 得，见实验方案 v1）。

> **严谨性注记（v1.4.0 验证后补充，见 `gestalt_verify_report.md` §4）**：实验观测的临界点 $\hat{W}_c^{\text{obs}}$ 由 Landau 序参量出现条件 $a(\hat{W}_c)=0$ 严格定义（即 $G\propto(\hat{W}-\hat{W}_c)^2$ 在 $\hat{W}>\hat{W}_c$ 非零）。上式 $\hat{W}_c=\sqrt{\alpha_1/\alpha_2}$ 实为"弱连接展开 $G=\alpha_1\hat{W}^2+\alpha_2\hat{W}^4$ 在 $\alpha_2<0$ 时的增益曲线峰值位置"，与 Landau 临界点**数学上不是同一量**。物理正确用法：实验中 $\hat{W}_c$ 取扫描观测到的能力跳变点；$\sqrt{\alpha_1/\alpha_2}$ 仅作弱连接拟合的辅助量，不可直接等同临界点。

### 2.5 统计物理路径总式

$$M = \sum_i s_i + \sum_{m\ge 1}\alpha_m \hat{W}^{2m}$$
与信息论路径**形式完全相同**。

## 3. 两条路径的统一

| 维度 | 信息论路径 | 统计物理路径 |
|------|-----------|-------------|
| 视角 | 微观（节点间信息共享） | 宏观（网络整体相变） |
| 偶次幂来源 | 互信息对连接符号偶（$\Delta(-w)=\Delta(w)$） | 对称性 $\phi\to-\phi$ |
| $W^{2m}$ 来源 | $m$ 条边协同的 $w^2$ 连乘 | Landau 自由能偶次展开 |
| 核心产物 | 协同增益的微观机制 | 临界点 $\hat{W}_c$ 与相变 |
| 可检验预言 | 协同增益随边数超线性增长 | 能力在 $\hat{W}_c$ 跳变 |

**统一结论**：两条独立框架殊途同归，均给出
$$M = \sum_i s_i + \sum_{m\ge 1}\alpha_m \hat{W}^{2m}$$
信息论提供"**为什么是偶次幂、为什么是 $W^{2m}$**"的微观解释；统计物理提供"**何时涌现（临界点）**"的宏观解释。两者互为支撑，不是单一类比。

## 4. 收敛性与规模无关性（补 v1.3.0 未竟之业）

**问题（v1.3.0 之前的"广延量陷阱"）**：若直接用 $W=\sum w_{ij}$，全连接 $k$ 节点时 $W_{\max}\propto k^2$，$W$ 随 $k$ 爆炸，级数 $\sum\alpha_m W^{2m}$ 必发散。

**修复**：改用 $\hat{W}=W/W_{\max}(k)\in[0,1]$。则：
$$\sum_{m\ge 1}\alpha_m \hat{W}^{2m}$$
在 $\hat{W}<1$ 时，只要 $|\alpha_m|^{1/m}$ 有界或随 $m$ 衰减，即**绝对收敛**。

- 收敛半径 $R=1$（以 $\hat{W}^2$ 为变量）；
- 临界点 $\hat{W}_c<1$ 落在收敛域内；
- $\hat{W}$ 不随网络规模 $k$ 增长，故**收敛性与 $k$ 无关**——大规模网络下方程依然 well-defined。

**物理截断说明**：实际高阶项因去相干（噪声、非理想连接）被自然抑制，$\alpha_m$ 随 $m$ 快速衰减，有限项（通常 $m\le 3$）即可描述实测涌现。无限阶幂级数仅为形式框架。

## 5. $\alpha_m$ 与拓扑的定量关系（理论方向，待实验量化）

这是全文最值钱的部分。给出**方向性公式**：
$$\alpha_m = A \cdot T_{\text{topo}}(m, k) \cdot \psi(s)$$
- $A$：普适常数（由基准套件与节点类型定）；
- $T_{\text{topo}}(m,k)$：**拓扑因子**，描述第 $m$ 阶协同在当前拓扑下被保留的程度；
- $\psi(s)$：节点能力耦合（强节点放大协同）。

| 拓扑 | $T_{\text{topo}}$ 特征 | 含义 |
|------|---------------------|------|
| 全连接 | 所有 $m$-边组合存在，$T$ 衰减最慢 | 各阶协同均强，$\alpha_m$ 最大 |
| 小世界 | 局部团 + 长程捷径，中阶保留、高阶衰减快 | $\alpha_1,\alpha_2$ 显著，$\alpha_3$ 骤降 |
| 分层 L3→L2→L1 | 层间耦合乘积，乘法涌现 | 总能力 $\approx \prod_{\text{层}}$ 层能力，等效高阶 |

**一旦用实验量化 $T_{\text{topo}}(m,k)$（见实验方案 v1 的 3 种拓扑扫描），文章即从"类比"升级为"理论"。**

## 6. 推导所依赖的假设（诚实声明）

| 假设 | 内容 | 可检验性 |
|------|------|---------|
| **A1** | 互信息对连接呈二次（$\Delta\propto w^2$），小相关展开 | 中/大 $w$ 时需用实验校准非线性项（加 $w^4$ 修正） |
| **A2** | $m$ 边协同为各边 $w^2$ 的连乘（PID/IIT 框架） | 可用协同信息直接测量验证 |
| **A3** | 平均场近似（边近似独立） | 稠密网络有效；极稀疏网络需修正（见拓扑因子） |

这三条假设**不是已证定理**，而是"有物理框架支撑、可实验证伪"的猜想。这正是下一步系统化实验（实验方案 v1）要钉死的对象。
