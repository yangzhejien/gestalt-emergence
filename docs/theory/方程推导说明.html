格式塔方程推导说明 · TMA 卡片版

从实测数据反推 M(W)=0.50+0.25·Nov(W) 为什么长这样、参数怎么定。所有数字均来自 live 实验 JSON（非记忆）。

① 起点：我们要从数据推导什么

先固定三个量，避免"涌现"一词被混用：

  • Acoll(W)：实测集体准确率（直接读 live json 的 collective_acc[cw1.00]）。
  • stop：同配置下最强单模型准确率（best_single）。
  • Ganchor(W) = Acoll(W) − stop：杨智杰提出的经验验证锚——"集体比最强单体多/少多少"。这是判断涌现成立的硬指标（G>0 且 beats_best=True 才判涌现）。
  • M(W)：本方程要定出的理论涌现度量，设计目标是有界、唯一内峰、非单调。

推导任务：用真实 Ganchor 数据，定出 M 的函数形状和三个参数 b、γ、Wc。

② 废案：原幂级数为什么不能用（必须先从数据证伪）

早期版本：M = Σsᵢ + Σ(αₘ−βₘ)Ẇ²ᵐ，临界公式 Wc=√(α₁/α₂)=1.491。

友人用两条数学理由证伪，数据也独立支持废案：

  • 数学错：β=0 时该项单调，无内峰；且 Wc=1.491 落在 [0,1] 归一化区间之外（真峰其实在 0.623），公式指错了位置。相加形式还破有界（可无限涨）。
  • 数据不支持单调：下面③的实测 Ganchor 在 C-Eval 上转负（−0.125 ~ −0.175），幂级数相加无法保证"过密回落且不到崩"。

结论：原方程废弃为最终形式，只保留其物理动机（协作增益 / 临界峰 / 冗余阻尼 / 集体>单体判据）作为思想来源，数学国面由友人重写。

④ 形状选择：为何是有界单峰核 Nov(W)

③ 的三条性质（有界 / 唯一内峰 / 左升右降）精确对应一个已知函数形式：

Nov(W) = WWc · e1 − W/Wc

性质核验（这是友人给的数学国面，不是拍脑袋）：

  • W → 0：Nov → 0（无密度无增益）。
  • W = Wc：Nov = 1·e0 = 1，唯一内峰恰=1。
  • W → ∞：Nov → 0（过密回落，不崩）。
  • 且 Nov ∈ [0,1] 处处有界。

它直接解释③的 C-Eval 反例：C-Eval 上小模型中文弱、与 7B 不互补 → 有效独立专家少 → 等效 W 已越过 Wc → Nov 落在右降支 → Ganchor 转负。形状与数据一一对应。

⑤ 参数标定 · b（地板）

证据：纯投票基线 committee0（聚合机制退化成多数投票时的底线）实测为——主基准 0.576~0.608，C-Eval 0.500~0.515。最保守值是 C-Eval k3 的 0.500。

标定：取 b = 0.50。

  • 它等于 4 选 1 随机基线（0.25）的 2 倍：即便协作最差（纯投票 + 硬基准），跨层"简报+残留"双通道仍保住 ≥0.50，不退化到随机——这是机制护城河的数据证据。
  • 同时是杨智杰原 Σsᵢ 加性基线思想的归一化体现（各层 solo 能力之和的最低有效部分）。

⑥ 参数标定 · γ（振幅）

证据：③ 中 |Ganchor| 实测最大 ≈ 0.175（C-Eval k3 负向），正向最大 0.106（E3 k5）。

标定：取 γ = 0.25，使 M ∈ [0.50, 0.75]。

  • 跨度 0.25 覆盖实测波动（0.175）且有余量，不至于把模型吹到失真。
  • γ 同时把原 (α−β) 净增益动机重编码为振幅：β（冗余阻尼）越大 → γ 越小 → 涌现越被抑。C-Eval 上小模型弱 → 冗余↑ → 等效 γ 被任务结构压低 → Ganchor 转负，与观测完全吻合。

⑦ 参数标定 · Wc（峰值位置）与诚实边界

已从数据锚定的部分：主基准 k=5(+0.106) > k=7(+0.094) 提示峰在 k≈5–6 的有效密度处；C-Eval k=3 已深负，证明 Wc 由"有效独立专家密度"而非裸 k 决定（支撑友人 Condorcet 陪审团机制：有效独立↑才有增益）。

诚实边界（必须写进论文 Limitations）：

  • 当前 Wc 数值 ≈0.45–0.62 来自友人仿真，并有主基准 k5/k7 拐点佐证，但真实 LLM 峰值扫描尚未完成。
  • 本机 CPU 只跑到 k=7；真正的密度扫描（k=12–20 / 节点 20+）需 eGPU，是待办项。写"Wc 由数据定位"前，必须先补这道扫描。

⑧ 最终方程 + 三秒自检

M(W) = b + γ · Nov(W) = 0.50 + 0.25 · WWc · e1 − W/Wc
  • W = Wc → Nov=1 → M = 0.50+0.25 = 0.75（峰，涌现最大潜力）
  • W → 0 → Nov→0 → M = 0.50（地板）
  • W → ∞ → Nov→0 → M = 0.50（过密回落，不崩）

落点全在 [0.50, 0.75]，与③实测 Ganchor 的有界非单调画像一致。这就是"从数据推出来"的闭环。
