## 3. 注册预测 vs 实测 逐条对照

### H1 结构性跨层涌现（集体 > comm0，所有密度）
- **注册**：集体在所有密度下 > committee-0（纯投票零模型）。
- **实测**：全体 G > 0（最低 +0.02）。
- **判定**：✅ 方向符合。但 n_l3=12 三档 G 均不显著（z = 0.20~1.43，p > 0.05），仅 n_l3=20 的 tree/mesh G = +0.24 显著（z = 2.55, p < 0.05）。即**结构性涌现的统计成立限于 n_l3=20 规模**。

### H2 临界相变（密度扫描，非单调）
注册排序预测：`Δ(tree@12) ≤ Δ(mesh@12) ≤ Δ(full@12) < 0 < Δ(full@20)`，且某更高密度点出现峰值后回落（β 项）。

| 子预测 | 实测 | 判定 |
|---|---|---|
| Δ(tree@12) ≤ Δ(mesh@12)（−0.16 ≤ −0.22） | 实际 mesh 更负 | ❌ 落空 |
| Δ(mesh@12) ≤ Δ(full@12)（−0.22 ≤ −0.10） | 成立 | ✅ |
| Δ(full@12) < 0（−0.10 < 0） | 成立 | ✅ |
| 0 < Δ(full@20)（后临界超过最强单体） | 实测 −0.16 < 0 | ❌ **落空（机制B未过）** |
| (a) Δ tree→mesh→full@12 单调趋近 0 | −0.16→−0.22→−0.10 不单调 | ❌ 落空 |
| (b) full@20 Δ > 0 | 同上行 | ❌ 落空 |
| (c) 更高密度峰值后回落（β） | n_l3=20 内 tree/mesh(0.74)→full(0.58) 回落 | ✅ 方向符合 |

### 小结
- **✅ 成立**：H1 方向（结构性涌现）；亚临界集体不超单体；非单调 + 过密回落（β）方向。
- **❌ 落空**：亚临界左翼单调趋近 0；具体排序 tree≤mesh；**full@20 后临界超过最强单体（超线性涌现临界 / 机制 B 未过）**。

## 4. 统计稳健性

- 各档 95% CI 见 §2（N=50，正态近似）。
- **tree@20 vs full@20 回落**：diff = 0.16，SE = 0.093，z = 1.71，**p ≈ 0.087，CI 重叠 → 统计不显著**。即 β 负干涉「方向对、量够、但未达显著」，需更大 n（如 n=200）或配对设计加固。
- **G 显著性**：仅 n_l3=20 tree/mesh 达显著；n_l3=12 整轮与 full@20 均在噪声范围内（不显著）。

## 5. 理论修订（基于实测）

- **尺度依赖**：注册将 n_l3=12 与 n_l3=20 混于同一排序，但实测表明**临界密度 Wc 随系统规模变**（有限尺度图像）——n_l3=12 整体处于亚临界噪声区，n_l3=20 结构性涌现方显著。须补 n_l3=14/16/18 钉死尺度依赖。
- **机制分层**：
  - 机制 A（结构性跨层涌现，集体 > 投票）在 n_l3=20 **成立**（显著）。
  - 机制 B（超线性涌现，集体 > 最强单体）**尚未跨过临界**——所有档集体 ≤ 7B(0.74)，最优 tree/mesh 仅追平。
- **核心瓶颈**：当前基准最强单体 3B = 0.79（> 7B），集体天花板余量过小，机制 B 无空间激活。下一步须造**更高难基准**（让单体降至 0.6–0.7、每层 sᵢ > 0.25），方能在正确难度区定位超线性临界 Wc。
