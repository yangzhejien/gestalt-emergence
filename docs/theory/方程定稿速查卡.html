🎯 最终统一方程（你要用的 / 现在所有实验都在用）

M(W) = b + γ · WWc · e1 − W/Wc

当前标定 b = 0.50, γ = 0.25 ，故 M ∈ [0.50, 0.75]

展开式：M(W) = 0.50 + 0.25 · (W/Wc) · e(1 − W/Wc)

新星核 Nov(W) = (W/Wc)·e(1−W/Wc) ∈ [0,1]，唯一内峰 ≡ 1 恰在 W = Wc。

涌现判据保留：G = collective − best_single（杨智杰贡献）。

❌ 原错误方程（2026-08-07 预注册，已废弃）

M = Σ si + Σ (αm − βm) Ẇ2m ， 临界公式 Wc = √(α1/α2) = 1.491

为什么错（友人独立核验）：

  • 净增益真峰在 0.623，不在 1.491；
  • β = 0 时函数单调、无内峰；
  • 公式还指到 [0,1] 区间外，实验根本扫不到 → 这是此前一直"撞墙"找不到 Wc 的根因。

✅ 友人修正方程（有界单峰 kernel）

M(W) = 0.50 + 0.25 · WWc · e1 − W/Wc

把无界幂级数替换为有界单峰核；Wc 重新定义为峰位本身；机制升级为 Condorcet 陪审团；Lean 部分机器证明。

🔧 "合出来"是怎么改的（不是两式相加！）

来源保留 / 改动落点
杨智杰（物理骨架）继承未动：协作增益、临界峰+过密回落、β抑制涌现、"集体>单体"判据、跨层乘法 H(L3)×H(L2|L3)×H(L1|L2)机制与判据

说明：相加会破坏有界性，故采用"概念继承 + 形式替换"。叫"完成"而非"推翻"。

📐 五个可证性质（靠它发顶刊）

  1. 有界：M ∈ [0.50, 0.75] ⊂ (0,1)，永不超合法准确率；
  2. 唯一内峰恰在 W = Wc；
  3. 非单调：W<Wc 升、W>Wc 降，留 0.50 地板；
  4. 无悬空公式：Wc 即峰位，消除"公式峰≠真峰"矛盾；
  5. 冗余阻尼：β 越大 → γ 越小 → 涌现被正确抑制。
