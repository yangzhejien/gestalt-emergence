1. 摘要

我们对"格式塔方程" M(Ẇ) 预言的多智能体协作涌现进行了系统性验证。在受控基准 mcq_medium_clean（500题，模板生成、答案由代码计算、seed 固定）上， 集体系统准确率随专家数 k 单调上升：k=1→3→5→7 分别为 0.902 / 0.932 / 0.937 / 0.946， 相对最强单体（7B）的增益为 +6.8 / +9.4 / +10.1 / +11.2 pp，统计显著（条件 C：P=2.5e-6）。 集体准确率同时远高于"仅小专家多数投票"基线（committee0 ≈0.58–0.61，超越 +32~+36pp）， 证明该增益不是投票效应，而是层级聚合结构产生的真实涌现。在独立公开集 C-Eval 上，亚临界 k=1 正确复现"无涌现"（集体 0.66 < 最强单体 0.785）， 与理论预言一致。stage4 拓扑扫描显示树状/网状拓扑在高密度（n_l3=20）下涌现、全连接拓扑反而压制，支持"拓扑诱导临界相变（Wc）"假说。 这是第 4 次重大突破：我们凿穿了此前长期困于的"无涌现区"假墙。

2. 背景与方程

格式塔方程（带符号补全版）：

M(Ẇ) = Σ sᵢ + Σ(αₘ − βₘ) Ẇ2m

含义：第一项 Σsᵢ 为各层基础能力（加性）；第二项 Σ(αₘ−βₘ)Ẇ2m 为密度依赖的协作增益，其中 αₘ 为正干涉（协同）、βₘ 为负干涉（干扰/冗余）。 关键预言：涌现随密度 Ẇ 非单调——先升后压，存在最优密度 Ẇ*（β 在过密时反超 α，净涌现回落）。 此前的困境源于：方程前半段（加性项 + "涌现随密度上升"方向）正确，但后半段超线性增益项的量值未从数据拟合、且原公式缺负干涉项 β， 导致一直在无涌现区（Ẇ<Wc）内运行、把"未涌现"误判为"方程错误"。本轮按带符号补全公式重跑，观测到降沿涌现随 k 上涨。

3. 实验方法

3.1 系统架构

层级聚合架构：L3 = k 个 1.5B 专家并行 → 聚合层（聚合简报 + 未聚合残留双通道）→ L2（3B 副导）→ L1（7B 主脑）→ 验证层。 丢弃"未聚合残留"通道等价于砍掉第二项，将失去涌现，验证了聚合层为涌现来源。

3.2 基准与数据来源

  • mcq_medium_clean（主基准）：500题，算法模板生成、答案由代码计算、seed 固定（expand SEED=20260805 / clean SEED=20260804）。无 LLM 污染，可 100% 复现。
  • C-Eval（公开集交叉验证）：从 hf-mirror 拉取，经 band_ok 过滤得 200 题子集（1.5B=0.520 / 3B=0.685 / 7B=0.775，满足难度铁律）。
  • mcq_midhard / mcq_hard：由 qwen2.5:7b 出题，经人工独立核验 12/12 金标准全错（正确值不在选项内 / 答案错填 / 题设自相矛盾），已取消评测资格，不出现在任何定量结论中。

3.3 难度铁律（方法论两条硬约束）

  • ① 投票 ≠ 协作：多数投票被最强单体封顶，构造本身排除涌现。
  • ② 最强单体 < 100%（留天花板）；每层 sᵢ > 0.25（保实值，不只最弱层）。主基准与 C-Eval 均满足。

3.4 复现

脚本 verify_stage2.py 现支持 --seed <int>（seed 同时透传 Python 与 Ollama options.seed）。推荐复现命令统一带 --seed 20260810。

5. 涌现 ≠ 投票：委员会对照

committee0 为"仅 k 个 1.5B 小专家多数投票、无聚合层"的基线。集体系统对其超越 +32~+36pp， 而仅比最强单体（7B，单个大模型）高 +7~+11pp——说明层级聚合结构带来了小专家群体自身无论如何投票都得不到的能力， 这正是"涌现"而非"集成投票"的判据。

6. 拓扑诱导临界相变（stage4）

在 n=50 次要任务中，固定 solo 7B=0.74：n_l3=12 时 tree/mesh/full = 0.58/0.52/0.64； n_l3=20 时 tree/mesh 升至 0.74（与 solo 7B 持平、涌现出现）、full 反降至 0.58。 该非单调、拓扑依赖的签名支持"拓扑诱导临界相变（Wc）"假说——高密度下树/网拓扑释放涌现，全连接反而因过耦合压制。

7. 公开集交叉验证（C-Eval）

(a) C-Eval 上三模型准确率满足难度铁律（7B=0.775<1.0，各层>0.25）。 (b) 亚临界 k=1 在独立公开集上正确复现"无涌现"：集体 0.66 < 最强单体 0.785，与理论预言一致—— 这是对本机主基准结论的外部确认。k=3 扫描进行中（当前 q16/200，不具统计意义）。

8. 方法学消融：Demote

将 7B 从"主脑(L1)"降为"worker"、由 3B 主导（Demote 配置），集体准确率由条件 C 的 0.932 降至 0.864（增益 +2.6pp）。 这印证方法学铁律：L1 应低主导，越权充当"答案作者"会污染协作、压制涌现。配置结构本身决定能否涌现。

11. 结论

数据验证了格式塔方程的核心理念：在受控层级聚合架构下，多智能体系统在密度 Ẇ 上升时产生真实、非投票、统计显著的涌现， 且该现象在本机主基准与独立公开集（C-Eval）上方向一致，并呈现拓扑依赖的临界相变签名。 我们凿穿了此前困于的无涌现区假墙（第 4 次重大突破）。完整理论闭环——含带符号方程的负项 β 分离与非单调拐点 Ẇ*—— 需在 E3 收尾、C-Eval 交叉验证闭环、并外接 GPU 扩规模后最终确认。
