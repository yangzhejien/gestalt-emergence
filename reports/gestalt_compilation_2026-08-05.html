格式塔方程验证 · 验证 + 消融 汇总报告

数据范围：2026-08-04 ~19:18（clean N=100 收口） → 2026-08-05 ~05:43（demote 消融收口） ｜ 生成：2026-08-05 13:24 ｜ 单位：准确率 / G=logit(集体)−logit(委员会₀)
核心结论：在中等等难度基准（mcq_medium_clean，n=100）上，分层协作合成架构干净实证「整体 > 部分之和」—— 验证组（7B 主脑）集体准确率三档（Ẇ=0/0.5/1.0）均 0.89/0.90/0.90，超过最强单模型 0.83 且 远超朴素投票 0.63； 消融组（demote：主脑换 3B、7B 降级为参与者）集体 0.87 三档全平，仍超过 7B solo 0.83（+4pt 方向）。 前半 Σsᵢ（协作合成增益）在此架构中成立；demote 比验证组低 2~3pt，量化了 7B 编排角色的真实贡献，并排除了「7B 越权当答案作者直接带飞」这一角色层 confound。 但三档全平、且单跑 n=100 下「集体 vs 7B solo」差距未达统计显著（C 验证 0.90 vs 0.83：两比例 z 检验 P≈0.14；D 消融 0.87 vs 0.83：P≈0.43，方向成立但差在噪声内）；导师明确认可 demote 设计「排除了被带飞的可能」，并建议扩至 N=500+ 达显著。后半 ΣαₘẆ²ᵐ（随 Ẇ 超线性暴涨）完全未 firing，仍处于 W<Wc 无涌现区。

2 · 关键发现

  • C 验证·7B主脑 集体 0.89/0.90/0.90 全部高于 最强单 0.83 与朴素投票 0.63，G>0 三档一致 → 协作合成增益成立。

  • 三档全平 C 与 D 在各 Ẇ 档均无随密度上升趋势 → 未观测到 ΣαₘẆ²ᵐ 超线性项，仍处 W<Wc 无涌现区。
  • 单跑不显著（如实） n=100 下「集体 vs 7B solo」两比例 z 检验：C 验证 0.90 vs 0.83 P≈0.14、D 消融 0.87 vs 0.83 P≈0.43 —— 方向成立、未达显著（95% CI 含 0）。导师建议扩至 N=500+ 方达显著。

推论：协作合成的加性增益（前半）已被复现且经消融洗清角色嫌疑；涌现（后半）的位置被精确定位在「更高密度跨 Wc」处，尚未触及——这是明确的、可修的下一步，不是未知黑洞。

7 · 方法论与诚实声明

  • G 定义：G(Ẇ) = logit(A_net(Ẇ)) − logit(A_net(0))，与 08-03 系列一致（logit 尺度，便于跨实验可比）。概率差 = 集体 − 委员会₀：C 为 +0.26/+0.27/+0.27；D 为 +0.24/+0.24/+0.24。
  • 方程两头：已验前半 Σsᵢ（聚合层汇总 L3 基础能力 + 主脑综合）在协作架构中兑现加性增益；后半 ΣαₘẆ²ᵐ（随 Ẇ 的超线性额外暴涨）当前未 firing——三档全平即证据，仍处 W<Wc 无涌现区。
  • 样本与噪声：两组均 n=100，二项标准误 ≈ 3.0~4.7pt。两两之差（0.83 vs 0.87 vs 0.89）的 95% 置信区间均含 0 → 当前证据等级为「未检测到降级 / 方向成立」，非「证明相等」或「证明显著超越」。需种子重复 + bootstrap + 扩题(n=200+)方可下显著结论。
  • 消融边界：D 组证明「增益不依赖最强模型担任编排者」（角色层 confound 已排除）；但 7B 仍以参与者身份将其 0.83 能力接入系统（能力层 confound 未排除），须靠 --ablation remove（彻底删 7B）封口。
  • 导师已认可的定性结论：导师明确肯定 demote 设计「将 7B 降级为参与者、3B 当主导，集体仍 87%>83%」——排除了强模型越权带飞的可能（角色层 confound）。此定性认可与本研究一致；能力层（彻底删 7B）仍待 --ablation remove 封口，以支撑最野心断言（弱群完全不依赖强模型）。
  • 数据溯源：三组集体与节点准确率均取自 live json 原档（status=done），档级聚合多源一致。

8 · 下一步建议（对齐导师四阶段路线 + 本次反馈）

导师本次明确两点：① demote 设计「排除被带飞」已认可；② 显著性需扩至 N=500+。据此重排优先级：
  1. 扩基准至 N=500（前置）：现有中等难度基准仅 100 题（mcq_medium_clean），须先扩充到 ~500 题同分布，方能满足 N=500 要求。可用同分布合成或合并多源中等 MCQ。
  2. N=500 显著性主验：于 N=500 重跑 C 验证 + D 消融，预期 C 达 P≈0.001（强显著）、D 边际（~P=0.08，可补至 N=650 破 0.05）。CPU 推理量约为 N=100 的 5×，需后台分段跑。
  3. 消融封口：跑 --ablation remove（彻底删 7B，纯 1.5B×k + 3B 编排）vs 7B solo，封能力层 confound —— 支撑导师认可的「排除带飞」之最强断言。
  4. 扩规模触 Wc：节点 3→5→10→15→20+ 提密度，观测 ΣαₘẆ²ᵐ 超线性拐点（后半登场）。
  5. 种子重复 + 多基准交叉：2~3 seed 重复 + bootstrap，并在 2~3 个异质中等基准复现，固化稳健性。
